# 🌍 Wanderlust

A full-stack travel listing web application inspired by Airbnb, built while learning the MERN Stack. The project focuses on understanding backend development with **Node.js**, **Express.js**, **MongoDB**, **Mongoose**, and **EJS** by implementing real-world CRUD operations, routing, validation, and error handling.

---

## 📖 About the Project

Wanderlust is a travel listing platform where users can browse different travel destinations and perform CRUD (Create, Read, Update, Delete) operations on listings.

The primary goal of this project is to gain hands-on experience with backend development, database management, server-side rendering, and RESTful architecture while following industry-standard coding practices.

---

## ✨ Features Implemented

* Display all travel listings
* View detailed information of a listing
* Create new travel listings
* Edit existing listings
* Delete listings
* Server-side form validation
* Custom error handling
* Responsive UI using Bootstrap
* RESTful routing
* MongoDB database integration
* EJS template rendering

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/codeWith-Vishal56/Wanderlust.git
```

Move into the project directory

```bash
cd Wanderlust
```

Install dependencies

```bash
npm install
```

Start MongoDB

```bash
mongod
```

Run the application

```bash
node app.js
```

Open your browser and visit

```
http://localhost:8080
```
